# Croco Store · Redesign concept (demo)

Unofficial, free redesign proposal for [crocostore.tn](https://crocostore.tn/), built to show the owner how the store could look and perform. **Not connected to the real store**: no orders, payments or customer data are processed.

## What's inside
- Next.js 15 (App Router, static export), TypeScript, Tailwind CSS 4. No other runtime dependency.
- 336 pre-rendered pages: home, shop, 8 categories, 30 brands, 282 product pages, packs, cart, checkout, wishlist, delivery, contact.
- Search with suggestions, filters (category, brand, price, stock, promo), sorting, quick view, wishlist, cart drawer, 2-step demo checkout.
- Mobile-first: bottom app bar, filter sheet, swipe gallery, sticky add-to-cart.

## Data
`src/data/*.json` is generated by `scripts/build_data.py` from a capture of crocostore.tn made on 21 Nov 2026
(products, TND prices, discounts, stock status, flavours, descriptions, pack contents, photos). Nothing is invented;
items that need confirmation are listed on `/a-propos-de-la-demo/`.

## Run
```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static site in ./out
```

## Deploy (free)
- **Vercel Hobby**: import this repo at vercel.com/new, keep defaults, deploy → `https://<project>.vercel.app`
- **GitHub Pages**: the included workflow builds with `NEXT_PUBLIC_BASE_PATH=/<repo>` and publishes `./out`.
- **Netlify / Cloudflare Pages**: build command `npm run build`, output directory `out`.

The site sets `noindex` so it never competes with crocostore.tn in search engines.
